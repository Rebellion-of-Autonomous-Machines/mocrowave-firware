# Modbus TCP / W5500: СВЧ-печь

## Подключение

- Modbus TCP: порт `502`, Unit ID `1`.
- W5500 CS: `GPIO5`.
- Статический адрес по умолчанию: `192.168.1.50`.
- Маска: `255.255.255.0`.
- Шлюз и DNS: `192.168.1.1`.
- Через Wi-Fi `awh` можно выбрать статический адрес или DHCP.

Поддерживаются функции `03` (Holding Registers), `04` (Input Registers), `06` (Write Single Register) и `16` (Write Multiple Registers).

Адреса вида `40001` и `30001` в Modbus-запросах передаются нулевыми смещениями: для обоих адресов используется offset `0`, но разные функции чтения.

## Holding Registers

| Адрес | Offset | Доступ | Название | Описание |
|---|---:|:---:|---|---|
| `40001` | `0` | RW | `Stat_Mode` | Состояние автоматики и запуск сценария |
| `40002` | `1` | RO | `Stat_Error` | Код ошибки автоматики |
| `40003` | `2` | RW | `Man_Control_C` | Неподдерживаемое ручное управление |
| `40004` | `3` | RW | `Man_Control_X` | Неподдерживаемое ручное управление |
| `40005` | `4` | RW | `Man_Control_Y` | Неподдерживаемое ручное управление |
| `40006` | `5` | RW | `Man_Control_Z` | Неподдерживаемое ручное управление |
| `40007` | `6` | RW | `Man_Time` | Уставка нагрева, секунды, `0..5999` |
| `40008` | `7` | RW | `Command` | Дополнительная совместимая команда |
| `40009` | `8` | RO | `Remaining_Time` | Оставшееся время нагрева, секунды |
| `40010` | `9` | RO | `Power_State` | Состояние реле нагрева |
| `40011` | `10` | RO | `Door_State` | Состояние двери |
| `40012` | `11` | RO | `Limit_State` | Битовое поле концевиков |
| `40013` | `12` | RO | `Motor_Direction` | Направление двигателя двери |
| `40014` | `13` | RO | `Permission_State` | Биты разрешённых действий |
| `40015` | `14` | RO | `Command_Result` | Результат последней команды |
| `40016` | `15` | RO | `Open_Remaining` | Оставшееся время открытия, секунды |

## Stat_Mode (`40001`)

| Значение | Назначение |
|---:|---|
| `1` | Готовность; сброс устранённой ошибки |
| `11` | Открыть дверь в течение 6 секунд |
| `12` | Запустить нагрев на время из `Man_Time` |
| `13` | Закрыть дверь до срабатывания DI5 |
| `19` | Сценарий завершён |
| `99` | Ошибка |

Сценарии `11`, `12` и `13` запускаются из состояния `1`. После состояния `19` или `99` перед следующим сценарием следует записать `1`.

Дверь работает только последовательно: после полностью закрытого положения разрешено только открытие, а после полного шестисекундного открытия — только закрытие. Пока дверь движется, любые команды записи игнорируются и не могут остановить или развернуть двигатель.

Нагрев по команде `12` разрешён только при замкнутом физическом концевике DI5 и состоянии двери «закрыта». Иначе реле не включаются, `Stat_Mode` становится `99`, а `Stat_Error` — `102`. Размыкание DI5 во время нагрева немедленно отключает реле и также устанавливает ошибку.

## Stat_Error (`40002`)

| Значение | Описание |
|---:|---|
| `0` | Ошибок нет |
| `100` | Требуется неподдерживаемый ручной режим |
| `101` | Устройство занято или команда подана во время другого сценария |
| `102` | Неизвестная команда, неверное состояние или нарушена защитная блокировка |
| `105` | Прямое ручное управление исполнительными устройствами запрещено |

При ошибке `Stat_Mode` принимает значение `99`. Запись `1` сбрасывает ошибку после завершения активного сценария.

## Man_Control (`40003–40006`)

Прямое ручное управление реле не поддерживается. Запись любого ненулевого значения очищает эти четыре регистра и устанавливает `Stat_Mode=99`, `Stat_Error=105`, `Command_Result=6`.

## Command (`40008`)

Дополнительный регистр сохраняет прежние высокоуровневые команды:

| Значение | Команда |
|---:|---|
| `0` | Нет команды |
| `1` | Открыть дверь |
| `2` | Закрыть дверь |
| `4` | Включить нагрев |
| `5` | Выключить нагрев |
| `6` | Сбросить ошибку и перейти в готовность |

Команда `4` использует `Man_Time` и проходит ту же аппаратную проверку DI5, что и `Stat_Mode=12`.

## Состояния

`Power_State` (`40010`): `0` — выключено, `1` — включение через резистор, `2` — шунт включён.

`Door_State` (`40011`): `0` — промежуточное/неизвестное положение, `1` — открыта, `2` — закрыта, `3` — открывается, `4` — закрывается.

`Limit_State` (`40012`): bit0 — виртуальный концевик открытия, bit1 — физический концевик закрытия DI5.

`Motor_Direction` (`40013`): `0` — не движется, `1` — открытие, `2` — закрытие.

`Permission_State` (`40014`): bit0 — нагрев, bit1 — открытие, bit2 — закрытие, bit3 — зарезервирован и всегда равен нулю, bit4 — изменение времени, bit5 — выключение нагрева. Bit0 устанавливается только при замкнутом DI5.

`Command_Result` (`40015`): `0` — OK, `1` — неизвестная команда, `2` — занято, `3` — запрещено состоянием, `4` — неверное значение, `6` — ручное управление запрещено.

## Input Registers

| Адрес | Offset | Название | Описание |
|---|---:|---|---|
| `30001` | `0` | `Tlm_TimeAll` | Общая наработка, целые часы, максимум `65535` |
| `30002` | `1` | `Tlm_TimeHeat` | Наработка нагрева, целые часы, максимум `65535` |
| `30021` | `20` | `Tlm_end_open` | Виртуальный концевик открытия, `0/1` |
| `30022` | `21` | `Tlm_end_closed` | Физический концевик закрытия DI5, `0/1` |

Виртуальный концевик открытия устанавливается после полного шестисекундного интервала открытия и сбрасывается при начале закрытия. Счётчики накапливаются в секундах и сохраняются во flash каждые 10 минут.

## Стартовая блокировка

После включения контроллер сначала закрывает дверь до DI5, но не дольше 15 секунд. Пока эта операция не закончена, HTTP-команды не обрабатываются, а Modbus-запись возвращает исключение `0x06` (`Server Device Busy`).

## Python-тестер

```bash
pip install pymodbus
python tools/modbus_tcp_tester.py
```

Тестер читает обе области регистров. Кнопка нагрева активна только при `30022=1` и установленном бите разрешения нагрева, но окончательное решение всегда принимает прошивка.
