# Modbus TCP / W5500

Управление микроволновой печью выполняется по Modbus TCP через Ethernet-модуль W5500.

## Сетевые параметры

- IP: `192.168.1.50`
- Маска: `255.255.255.0`
- Gateway: `192.168.1.1`
- DNS: `192.168.1.1`
- TCP порт: `502`
- Unit ID: `1`
- W5500 CS: `GPIO5`

В веб-интерфейсе точки доступа Wi-Fi `awh` можно выбрать статическую настройку сети или DHCP. Для статического режима задаются IP-адрес, маска подсети, шлюз и DNS. Настройки сохраняются во flash-памяти контроллера и применяются сразу, без перезагрузки платы. Указанные выше значения используются по умолчанию до первого сохранения настроек. Интерфейс также показывает состояние линии, текущие параметры W5500 и IP-адрес с портом подключённого клиента Modbus TCP.

Во время автоматического закрытия двери после включения контроллера команды записи Modbus временно отклоняются с исключением `0x06` (`Server Device Busy`). Обработка команд начинается после срабатывания концевика закрытия или истечения тайм-аута `15` секунд.

## Поддерживаемые функции Modbus

- `03` Read Holding Registers
- `06` Write Single Register
- `16` Write Multiple Registers

Адреса регистров указаны в нулевой адресации.

## Holding registers

| Адрес | Доступ | Имя | Описание |
|---:|:---:|---|---|
| `0` | RW | `COMMAND` | Команда управления. После обработки внутренне сбрасывается в `0`. |
| `1` | RW | `SET_TIME_SECONDS` | Уставка времени в секундах, диапазон `0..5999`. |
| `2` | RO | `REMAINING_TIME_SECONDS` | Оставшееся время в секундах. |
| `3` | RO | `POWER_STATE` | Состояние нагрева. |
| `4` | RO | `DOOR_STATE` | Состояние двери. |
| `5` | RO | `LIMIT_SWITCH_STATE` | Битовое поле концевика закрытия DI5. |
| `6` | RO | `MOTOR_DIRECTION` | Направление привода двери. |
| `7` | RO | `PERMISSION_STATE` | Битовое поле разрешений команд. |
| `8` | RO | `COMMAND_RESULT` | Результат последней команды. |
| `9` | RO | `ERROR_CODE` | Код ошибки. |
| `10` | RO | `OPEN_REMAINING_SECONDS` | Оставшееся время открытия двери по таймеру. |

## COMMAND

Запись в регистр `0`.

| Значение | Команда |
|---:|---|
| `0` | Нет команды |
| `1` | Открыть дверь |
| `2` | Закрыть дверь |
| `3` | Остановить привод двери |
| `4` | Включить нагрев |
| `5` | Выключить нагрев |
| `6` | Сбросить ошибку |

## POWER_STATE

Регистр `3`.

| Значение | Состояние |
|---:|---|
| `0` | Нагрев выключен |
| `1` | Нагрев включен, шунт пускового резистора еще не включен |
| `2` | Нагрев включен, шунт включен |

## DOOR_STATE

Регистр `4`.

| Значение | Состояние |
|---:|---|
| `0` | Между положениями |
| `1` | Открыта |
| `2` | Закрыта |
| `3` | Открывается |
| `4` | Закрывается |

Открытие выполняется по времени: привод включается на `6` секунд, затем автоматически останавливается.

Закрытие выполняется до срабатывания концевика закрытого положения `DI5`.

## LIMIT_SWITCH_STATE

Регистр `5`.

| Бит | Описание |
|---:|---|
| `0` | `1` - концевик закрытия DI5 замкнут, `0` - разомкнут |

## MOTOR_DIRECTION

Регистр `6`.

| Значение | Состояние |
|---:|---|
| `0` | Стоп |
| `1` | Открытие |
| `2` | Закрытие |

## PERMISSION_STATE

Регистр `7`.

| Бит | Описание |
|---:|---|
| `0` | Разрешено включение нагрева |
| `1` | Разрешена команда открытия двери |
| `2` | Разрешена команда закрытия двери |
| `3` | Разрешена команда остановки привода двери |
| `4` | Разрешено изменение уставки времени |
| `5` | Разрешено выключение нагрева |

## COMMAND_RESULT

Регистр `8`.

| Значение | Результат |
|---:|---|
| `0` | OK |
| `1` | Неизвестная команда |
| `2` | Устройство занято |
| `3` | Команда запрещена текущим состоянием |
| `4` | Недопустимое значение |

## ERROR_CODE

Регистр `9`.

| Значение | Ошибка |
|---:|---|
| `0` | Нет ошибки |
| `1` | При старте дверь не дошла до закрытого положения за `15` секунд |
| `2` | Попытка включить нагрев при незакрытой двери |
| `3` | Попытка включить нагрев при нулевом времени |
| `4` | Команда двери отклонена во время нагрева |

## Примеры

Установить время `30` секунд:

```text
Write register 1 = 30
```

Включить нагрев:

```text
Write register 0 = 4
```

Открыть дверь:

```text
Write register 0 = 1
```

Закрыть дверь:

```text
Write register 0 = 2
```
