Руководство оператора

Аннотация

Настоящий документ предназначен для операторов, использующих программное обеспечение "СВЧ печь".

Управление изделием выполняется только по протоколу Modbus RTU.

Документ содержит назначение программы, условия выполнения, порядок управления изделием, карту регистров Modbus и перечень основных сообщений оператору.

1 Назначение программы

1.1 Функциональное назначение программы

Программа предназначена для управления СВЧ печью по протоколу Modbus RTU.

Программа обеспечивает управление нагревом, таймером рабочего цикла, приводом двери, концевыми выключателями двери и силовыми реле изделия.

1.2 Состав функций

Программа обеспечивает выполнение следующих функций:

* прием команд управления по Modbus RTU;
* установка времени рабочего цикла;
* запуск нагрева при закрытой двери;
* остановка нагрева по команде оператора;
* автоматическое отключение нагрева по окончании таймера;
* включение силовых реле фазы и нуля;
* шунтирование пускового резистора через 200 мс после включения питания нагрузки;
* открытие двери;
* закрытие двери;
* остановка привода двери;
* автоматическая остановка привода по концевику открытого положения;
* автоматическая остановка привода по концевику закрытого положения;
* блокировка нагрева при незакрытой двери;
* автоматическое закрытие двери при включении питания, если дверь находится в промежуточном положении;
* выдача статусов изделия по Modbus RTU.


2 Условия выполнения программы

2.1 Минимальный состав аппаратных средств

Для функционирования программы необходим контроллер на базе ESP32.

К контроллеру должны быть подключены следующие аппаратные узлы:

* модуль релейных выходов на базе PCF8574 с адресом I2C 0x24;
* модуль дискретных входов на базе PCF8574 с адресом I2C 0x22;
* интерфейс Modbus RTU;
* исполнительные реле фазы, нуля, шунта резистора и привода двери;
* концевой выключатель закрытого положения двери DI5;
* концевой выключатель открытого положения двери DI6.

Назначение реле:

* реле 1 - фаза питания нагрузки;
* реле 2 - ноль питания нагрузки;
* реле 3 - шунт пускового резистора;
* реле 5 - первая линия реверсивного управления приводом двери;
* реле 6 - вторая линия реверсивного управления приводом двери.

Назначение входов:

* DI5 - концевой выключатель закрытого положения двери;
* DI6 - концевой выключатель открытого положения двери.

2.2 Минимальный состав программных средств

Для обмена с изделием необходимо использовать управляющее устройство или программу, поддерживающую Modbus RTU.

Управляющее устройство должно поддерживать следующие функции Modbus:

* 03 Read Holding Registers;
* 06 Write Single Register;
* 16 Write Multiple Registers.

2.3 Требования к персоналу

Оператор должен обладать навыками работы с оборудованием, управляемым по Modbus RTU.

Оператор должен знать назначение команд управления, уметь читать и записывать регистры Modbus, а также контролировать состояние двери и нагрева по регистрам статуса.


3 Управление по протоколу Modbus RTU

3.1 Параметры связи

Тип протокола: Modbus RTU.

Скорость обмена: 9600 бит/с.

Формат кадра: 8N1.

Количество бит данных: 8.

Контроль четности: отсутствует.

Количество стоп-бит: 1.

Адрес устройства Modbus задается в прошивке изделия. Если адрес не задан отдельно, используется адрес 1.

3.2 Карта регистров

В таблице приведена карта регистров, принятая для управления функциями, реализованными в программе.

Адреса указаны в нулевой адресации Modbus.

Регистр 0. COMMAND.

Тип доступа: запись.

Назначение: запись команды управления.

Допустимые значения:

* 0 - нет команды;
* 1 - открыть дверь;
* 2 - закрыть дверь;
* 3 - остановить привод двери;
* 4 - включить нагрев;
* 5 - выключить нагрев;
* 6 - сбросить ошибку.

После выполнения команды устройство должно сбросить внутреннее значение команды в 0.

Регистр 1. SET_TIME_SECONDS.

Тип доступа: чтение/запись.

Назначение: уставка времени рабочего цикла в секундах.

Диапазон значений: от 0 до 5999 секунд.

Соответствие диапазону интерфейса таймера: от 00:00 до 99:59.

При значении 0 запуск нагрева запрещен.

Регистр 2. REMAINING_TIME_SECONDS.

Тип доступа: чтение.

Назначение: оставшееся время рабочего цикла в секундах.

Во время нагрева значение уменьшается один раз в секунду.

При ручном или автоматическом выключении нагрева значение возвращается к уставке последнего запуска.

Регистр 3. HEATING_STATE.

Тип доступа: чтение.

Назначение: состояние нагрева.

Допустимые значения:

* 0 - нагрев выключен;
* 1 - нагрев включен, нагрузка подключена через пусковой резистор;
* 2 - нагрев включен, пусковой резистор зашунтирован.

Регистр 4. DOOR_STATE.

Тип доступа: чтение.

Назначение: состояние двери.

Допустимые значения:

* 0 - дверь находится между конечными положениями;
* 1 - дверь открыта;
* 2 - дверь закрыта;
* 3 - дверь движется на открытие;
* 4 - дверь движется на закрытие.

Регистр 5. LIMIT_SWITCH_STATE.

Тип доступа: чтение.

Назначение: состояние концевых выключателей двери.

Формат: битовое поле.

Бит 0:

* 0 - концевой выключатель закрытого положения DI5 разомкнут;
* 1 - концевой выключатель закрытого положения DI5 замкнут.

Бит 1:

* 0 - концевой выключатель открытого положения DI6 разомкнут;
* 1 - концевой выключатель открытого положения DI6 замкнут.

Регистр 6. DOOR_MOTOR_STATE.

Тип доступа: чтение.

Назначение: состояние привода двери.

Допустимые значения:

* 0 - привод остановлен;
* 1 - привод выполняет открытие;
* 2 - привод выполняет закрытие.

Регистр 7. PERMISSION_STATE.

Тип доступа: чтение.

Назначение: разрешения на выполнение команд.

Формат: битовое поле.

Бит 0:

* 0 - запуск нагрева запрещен;
* 1 - запуск нагрева разрешен.

Бит 1:

* 0 - команда открытия двери запрещена;
* 1 - команда открытия двери разрешена.

Бит 2:

* 0 - команда закрытия двери запрещена;
* 1 - команда закрытия двери разрешена.

Бит 3:

* 0 - команда остановки привода двери запрещена;
* 1 - команда остановки привода двери разрешена.

Бит 4:

* 0 - изменение уставки времени запрещено;
* 1 - изменение уставки времени разрешено.

Бит 5:

* 0 - выключение нагрева запрещено;
* 1 - выключение нагрева разрешено.

Регистр 8. ERROR_CODE.

Тип доступа: чтение.

Назначение: код текущей ошибки.

Допустимые значения:

* 0 - ошибок нет;
* 1 - дверь не дошла до закрытого положения при автоматическом закрытии после включения питания;
* 2 - одновременно активны концевые выключатели DI5 и DI6;
* 3 - команда включения нагрева отклонена, дверь не закрыта;
* 4 - команда включения нагрева отклонена, уставка времени равна 0;
* 5 - команда движения двери отклонена, нагрев включен.

Регистр 9. STARTUP_CLOSE_TIMEOUT_SECONDS.

Тип доступа: чтение.

Назначение: предельное время автоматического закрытия двери после включения питания.

Значение: 15 секунд.

Регистр 10. SHUNT_DELAY_MS.

Тип доступа: чтение.

Назначение: задержка включения реле шунта пускового резистора после включения нагрева.

Значение: 200 мс.

3.3 Команды управления

Для передачи команды оператор должен записать код команды в регистр COMMAND.

Команда "Открыть дверь" выполняется записью значения 1 в регистр COMMAND.

Команда разрешена только если:

* нагрев выключен;
* привод не выполняет открытие;
* концевой выключатель открытого положения DI6 не замкнут;
* дверь не находится в состоянии "Открыта".

При выполнении команды привод двери включается на открытие.

При срабатывании DI6 привод автоматически отключается.

Команда "Закрыть дверь" выполняется записью значения 2 в регистр COMMAND.

Команда разрешена только если:

* нагрев выключен;
* привод не выполняет закрытие;
* концевой выключатель закрытого положения DI5 не замкнут;
* дверь не находится в состоянии "Закрыта".

При выполнении команды привод двери включается на закрытие.

При срабатывании DI5 привод автоматически отключается.

Команда "Остановить привод двери" выполняется записью значения 3 в регистр COMMAND.

Команда разрешена только если:

* нагрев выключен;
* привод двери находится в движении;
* дверь не находится в полностью открытом положении;
* дверь не находится в полностью закрытом положении.

Команда "Включить нагрев" выполняется записью значения 4 в регистр COMMAND.

Команда разрешена только если:

* нагрев выключен;
* уставка времени больше 0;
* концевой выключатель закрытого положения DI5 замкнут;
* дверь находится в состоянии "Закрыта".

Если дверь не закрыта, команда включения нагрева должна быть отклонена.

Команда "Выключить нагрев" выполняется записью значения 5 в регистр COMMAND.

При выполнении команды выключаются реле фазы, нуля и шунта.

После выключения нагрева оставшееся время возвращается к уставке последнего запуска.

Команда "Сбросить ошибку" выполняется записью значения 6 в регистр COMMAND.

Команда используется для сброса текущего кода ошибки после устранения причины ошибки.

3.4 Статусы изделия

Оператор должен контролировать состояние изделия чтением регистров статуса.

Перед включением нагрева оператор должен убедиться, что:

* регистр DOOR_STATE имеет значение 2;
* бит 0 регистра LIMIT_SWITCH_STATE равен 1;
* бит 0 регистра PERMISSION_STATE равен 1;
* регистр ERROR_CODE имеет значение 0.

Во время нагрева оператор должен контролировать:

* регистр REMAINING_TIME_SECONDS;
* регистр HEATING_STATE;
* регистр ERROR_CODE.

Во время движения двери оператор должен контролировать:

* регистр DOOR_STATE;
* регистр DOOR_MOTOR_STATE;
* регистр LIMIT_SWITCH_STATE;
* регистр ERROR_CODE.

3.5 Порядок выполнения рабочего цикла

Для выполнения рабочего цикла оператор должен:

* записать требуемую уставку времени в регистр SET_TIME_SECONDS;
* убедиться, что дверь закрыта по регистру DOOR_STATE;
* убедиться, что концевик DI5 замкнут по регистру LIMIT_SWITCH_STATE;
* убедиться, что запуск нагрева разрешен по регистру PERMISSION_STATE;
* записать значение 4 в регистр COMMAND;
* контролировать уменьшение значения регистра REMAINING_TIME_SECONDS;
* дождаться автоматического выключения нагрева или выполнить команду выключения нагрева.

При запуске нагрева программа включает реле фазы и нуля.

В течение первых 200 мс нагрузка работает через пусковой резистор.

Через 200 мс программа включает реле шунта пускового резистора.

После окончания таймера программа выключает все реле нагрева.

3.6 Управление дверью

Для открытия двери оператор должен:

* убедиться, что нагрев выключен;
* убедиться, что команда открытия разрешена по регистру PERMISSION_STATE;
* записать значение 1 в регистр COMMAND;
* контролировать состояние регистра DOOR_STATE;
* дождаться перехода двери в состояние "Открыта".

Для закрытия двери оператор должен:

* убедиться, что нагрев выключен;
* убедиться, что команда закрытия разрешена по регистру PERMISSION_STATE;
* записать значение 2 в регистр COMMAND;
* контролировать состояние регистра DOOR_STATE;
* дождаться перехода двери в состояние "Закрыта".

Если дверь остановлена в промежуточном положении, оператор должен подать команду открытия или закрытия.

При включении питания программа проверяет состояние концевиков двери.

Если оба концевика отжаты, дверь считается находящейся в промежуточном положении.

В этом случае программа автоматически включает закрытие двери.

Если в течение 15 секунд DI5 не срабатывает, привод двери останавливается, а запуск нагрева остается запрещенным.

3.7 Завершение работы

Перед снятием питания с изделия оператор должен:

* выключить нагрев командой 5;
* убедиться, что регистр HEATING_STATE имеет значение 0;
* остановить привод двери, если он находится в движении;
* убедиться, что регистр ERROR_CODE имеет значение 0 или зафиксировать текущую ошибку.


4 Сообщения оператору

Сообщения оператору передаются через регистры состояния и кодов ошибок Modbus.

Информационные состояния:

* нагрев выключен;
* нагрев включен через пусковой резистор;
* нагрев включен, резистор зашунтирован;
* дверь открыта;
* дверь закрыта;
* дверь в движении;
* дверь между положениями.

Предупреждающие состояния:

* запуск нагрева запрещен, дверь не закрыта;
* запуск нагрева запрещен, время не задано;
* управление дверью запрещено, нагрев включен;
* команда открытия запрещена, дверь уже открыта;
* команда закрытия запрещена, дверь уже закрыта.

Ошибочные состояния:

* дверь не дошла до закрытого положения при автоматическом закрытии после включения питания;
* одновременно активны концевые выключатели DI5 и DI6;
* команда отклонена из-за несоблюдения условий безопасности.

DI - дискретный вход.

I2C - последовательная шина обмена данными между микросхемами.

Modbus RTU - протокол обмена данными по последовательному интерфейсу.

PCF8574 - микросхема расширителя дискретных входов/выходов.

RTU - режим передачи Modbus по последовательной линии.

СВЧ - сверхвысокая частота.
